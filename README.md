# 🧮 Basic Calculator (Web App)

## 📌 Description
This is a simple web-based calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations like addition, subtraction, multiplication, and division with a clean and responsive user interface.

## 🚀 Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📱 Responsive design (works on mobile & desktop)
- 🎯 Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML (Structure)
- CSS (Styling)
- JavaScript (Functionality)
